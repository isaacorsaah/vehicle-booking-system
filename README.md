# Vehicle Booking System

A Java console application for managing passenger and vehicle
records, based on an object-oriented programming coursework
starter project.

## Technologies

Java, Maven, and JUnit.

## Existing features

- Load passenger and vehicle records from text files.
- Display passenger and vehicle information.
- Search passengers by name.
- Model vehicles using inheritance.

## Design

PassengerStore handles passenger records.
VehicleManager handles vehicle records.
Vehicle and Van demonstrate inheritance.
AppMenu provides the console interface.

## Current limitations

Booking functionality is incomplete. Vehicle menu actions are
not connected, and adding passengers uses hardcoded sample data.

## Improvement plan

- Replace hardcoded passenger details with validated user input.
- Complete vehicle and booking operations.
- Add tests for search, validation, and persistence.
- Add verified setup instructions and an example walkthrough.

## Background

Originally developed from supplied coursework starter code.
